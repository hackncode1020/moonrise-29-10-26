# Moonrise Tracker 🌙❤️

**Karwa Chauth Mode: ON.** A tiny app for your wife or husband on Karwa Chauth, made with plain HTML, CSS & JavaScript (canvas, no libraries, no images).

🔗 **Live:** https://moonrise-hackncode.sites.tab.bot/

## What happens
1. Type your chaand's name and press **Start 🌙**
2. A live **"Moonrise in 00:00:05"** countdown ticks down (the demo runs fast)
3. The fasting bar sits at **"Fasting for you since sunrise ❤️ 99%"** with stats: Water: 0 💧 · Patience: ∞ · Love: 100%
4. At zero the **moon rises over the city skyline**, the bar hits **100%** with a soft glow burst
5. The screen writes **"Chaand nikal aaya 🌙"**, then **"Tum mera chaand ho, &lt;name&gt; ❤️"** and **Happy Karwa Chauth 🪔**

Share a personalised link: `https://moonrise-hackncode.sites.tab.bot/?name=YourLove` (with no name it says "my love").

## Files
- `index.html` – app layout: mode toggle, tracker card, name box, Start / Share / Replay
- `style.css` – dark glass "app" theme, mobile-first
- `script.js` – countdown, fasting bar, moonrise over the skyline, glow burst, typing text

## Run it
Just open `index.html` in a browser. That's it.
